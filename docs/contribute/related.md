## Recipe Scraper

While not directly related to Stillroom, we make extensive use of the brilliant [recipe-scrapers](https://github.com/hhursev/recipe-scrapers)
package by hhursev.

If you have the skills to add new sites or help resolve issues you are indirectly helping Stillroom.

## Unofficial mobile apps

### kitshn

Unofficial client originally built for Tandoor Recipes. It talks the same API Stillroom still serves.

Maintained by [Aimo](https://github.com/aimok04/kitshn)

- Website: [https://kitshn.app/](https://kitshn.app/)
- Appstores: [Apple](https://apps.apple.com/us/app/kitshn-for-tandoor/id6740168361), [Android](https://play.google.com/store/apps/details?id=de.kitshn.android)

## GPT Recipe

Maintained by [John Pedrie](https://github.com/jdpedrie/gpt-recipe)

Convert pictures of recipes to a structure that can be imported to Stillroom with ChatGPT.

## tandoor-menu-generator

Maintained by [smilerz](https://github.com/smilerz/tandoor-menu-generator)

Generate a meal plan based on complex criteria and optionally insert it into an SVG menu template. Originally written for Tandoor Recipes; it works with Stillroom as well.

## Morsl

Maintained by [featurecreep-cron](https://github.com/featurecreep-cron/morsl)

Automate meal planning for Stillroom. Set up profiles with filter rules — rating, books, tags, recently cooked — and generate meal plans that sync directly to Stillroom. Supports automatic generation and a shareable menu for household members.
